# WORM-GPT

### Defensive Cybersecurity & Digital Forensics Toolkit

WORM-GPT is a Python-based defensive security toolkit
designed to help users analyze suspicious emails, URLs,
IP addresses, and files.

## Features

- Email Security Analysis
- URL Threat Analysis
- IP Intelligence
- File SHA256 Analysis
- Investigation History
- Security Dashboard
- VirusTotal Integration (Optional)
- AbuseIPDB Integration (Optional)

## Requirements

- Python 3
- Termux or Linux
- Requests library
